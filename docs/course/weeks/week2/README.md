# ISM 310 Week 2 classroom practice

Daily assessment practice for Dr. George Antoniou’s Defense in Depth course. This continues the Week 1 fictional Harbor Books case. All additional evidence records, financial values, and recovery objectives are explicitly fictional classroom inputs.

## Student use
Open index.html locally in a modern browser, or use the published Pages URL. No student GitHub account, installation, API key, or sign-in is required. Core exercises work offline. External source links require internet.

Monday B1–B2: approach selection and illustrative loss estimates.
Tuesday B3–B4: evidence chains and assessment plans versus findings.
Wednesday B5–B6: activity dependencies and recovery objectives; Joe Ingles leads.
Thursday B7–B8: threat/vulnerability/exploit analysis and gap verification; Joe Ingles leads.

All exercises are ungraded. Answer explanations are intentionally public. The interface is not a secure assessment and does not assign course grades. Open reasoning receives discussion prompts, not automated evaluation of writing quality.

## Saving and privacy
Entries stay in browser memory unless Save on this device is selected. Saving uses browser localStorage under a Week 2-specific key, separate from Week 1. Download exports only the student's notes as JSON. No responses are submitted to Canvas, an instructor dashboard, or a server by this code. No external script dependencies or analytics are included. Browser storage may be restricted; use download as an alternative. Clear saved entries on shared devices. Do not enter names, credentials, real logs, confidential data, or graded submission text.

## Publishing
This practice ZIP is the only folder intended for public GitHub hosting. Upload its extracted contents so index.html is at the publishing root. No build step is required. Configure Pages using the current official instructions and verify the resulting published URL:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

Keep the instructor and Joe teaching guides private. Do not upload the complete faculty package to a public repository. Preserve Week 1 separately, for example in a week1 folder, and put this content in a week2 folder if using one teaching repository. Link the actual resulting week2 URL in Canvas after verification.

## Canvas placement
Use one shared Week 2 practice URL. Link it before homework in the existing four module sections:
- Defining Risk Assessment Approaches: B1–B2.
- Performing a Risk Assessment: B3–B4.
- Identifying Assets and Activities to Be Protected: B5–B6.
- Identifying and Analyzing Threats, Vulnerabilities, and Exploits: B7–B8.

The supplied updated syllabus assigns these four topics to Week 2. Detailed risk-mitigation security controls remain Week 3. Do not move or recreate existing assignments. Browser exports are optional practice notes, not new graded submissions.
