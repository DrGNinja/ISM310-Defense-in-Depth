# ISM 310 Week 4 classroom practice

Practice continuity, recovery, incident response, and final presentation readiness for Dr. George Antoniou’s Defense in Depth course. The unchanged Harbor Books base case continues from earlier weeks. All additional disruption updates, test records, recovery targets, and response records are explicitly fictional classroom inputs.

## Daily use
Open index.html in a modern browser or use the verified GitHub Pages URL. No student sign-in, account, software install, API, or build step is required. Core exercises run offline; external source links need internet. The Word workbook gives an offline alternative.

Monday November 9: D1 continuity decision workshop and D2 continuity phases. BIA review and BCP, Chapters 12 review and 13.
Tuesday November 10: D3 recovery sequence and D4 acceptance evidence. DRP, Chapter 14.
Wednesday November 11: D5 incident triage and D6 verification/closure. CIRT, Chapter 15.
Thursday November 12: D7 five-minute readiness check and D8 five-minute reflection around oral presentations. These are not additional lectures or graded submissions.

All practice is ungraded. Answer explanations are public and visible in the client code. Open reasoning receives coaching prompts, not automatic grading of writing or decisions. Selection checks cover the stated toy exercise only. No presentation content is analyzed or approved automatically.

## Saving and privacy
Entries remain in page memory unless Save on this device is selected. Optional persistence uses a Week 4-specific localStorage key separate from prior weeks. Download produces JSON notes including checkbox states. This code sends no notes to Canvas, a model, an instructor dashboard, or a server. No external dependencies or analytics are built in. Hosting may retain normal access logs. Browser settings may block device storage; download notes as an alternative. Clear notes on shared devices. Do not enter names, credentials, private records, classmates’ details, or graded submission text.
