# ISM 310 Week 3 classroom practice

Eight ungraded activities for Dr. George Antoniou’s Defense in Depth course. This continues the fictional Harbor Books case from Weeks 1 and 2. All extra budgets, costs, impact tolerances, evidence records, and numerical estimates are explicitly fictional practice inputs.

## Daily use
Open index.html in a modern browser or use a verified GitHub Pages URL. No student account, install, API key, or build step is needed. The core activities work offline. External reference links need internet.

Monday November 2: C1 treatment decisions and C2 constrained prioritization.
Tuesday November 3: C3 control classification and C4 verification evidence.
Wednesday November 4: C5 impact over time and C6 cost-benefit sensitivity.
Thursday November 5: C7 implementation sequence and C8 monitoring claims.

The Word workbook gives an offline alternative. Feedback is public practice guidance, not secure assessment. Open reasoning receives peer-review prompts, not automatic grading of writing or decisions. Numeric and selection checks cover only the stated toy exercise.

## Privacy and saving
Entries remain in page memory until the student chooses Save on this device. Optional saving uses a Week 3-specific localStorage key. Download produces JSON notes including checkbox states. No notes are sent to Canvas, an instructor dashboard, a model, or a server by this code. No external dependencies or analytics are included. Hosting itself may maintain standard access logs. Browser settings can block local saving, so download notes before leaving. Clear saved notes on shared devices. Do not enter names, credentials, confidential records, or graded submission text.
