# ISM 310 Week 1 classroom practice

Original fictional practice for Dr. George Antoniou’s Defense in Depth course.

## Student use
Open index.html in a modern browser, or use the published GitHub Pages link supplied by the instructor. No student GitHub account, installation, API key, or sign-in is required. External source links need internet access. The core activities work offline.

Monday A1–A2: terminology, evidence, and complementary controls.
Tuesday A3–A4: risk statements, illustrative scoring, and treatment evidence.
Wednesday A5–A6: source authority, applicability, and evidence.
Thursday A7–A8: one planning decision, tabletop reasoning, and AI claim checking.

The exercises are ungraded. The feedback is intentionally visible and must not be used as a secure assessment. Prose and planning decisions receive discussion prompts, not automated grades.

## Notes and privacy
Entries live in page memory unless the student clicks Save on this device. That option uses browser localStorage. Downloads are JSON files of the student's own notes. No data is submitted to Canvas, an instructor dashboard, or a server. Clear entries on shared devices. Do not enter names, credentials, private information, or graded submissions.

## Instructor publishing
Upload only the contents of this practice folder to the repository selected for student practice. Keep index.html at the publishing root. No build step or external JavaScript library is required. GitHub Pages supports static HTML, CSS, and JavaScript. Configure the repository's Pages publishing source and verify the resulting public URL. Follow current official GitHub instructions:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

Do not upload the instructor guide or the full teaching package to the public practice repository. The Word student workbook provides a parallel offline path.

## Canvas placement
Link the published Pages URL as an external learning resource near the beginning of each of the four Week 1 module sections. Name it “Week 1 classroom practice” and indicate the relevant activity IDs. Use one shared URL. Do not make exports a graded submission unless a separate explicit assignment is created by the professor.

## Maintenance
The fictional case and all interface text are embedded in index.html. The file includes its CSS and JavaScript and needs no CDN dependencies. Content corrections can be made in that file. No dates or assignments are automatically synchronized with Canvas. Answer keys reside in client code and are public by design.
